# AI Trading Plan

Railway migration of the existing AI Trading Plan Hatchable application.

This project is intentionally separate from `ai-trading-SMC`.

Migration target:
- XAUUSD / BTCUSD trading plan
- MT5 market/account bridge
- Historical entries and performance
- Telegram notifications
- Morning plan and daily recap
- PostgreSQL persistence
- Breakeven protection and trade command infrastructure

The original Hatchable application remains unchanged during migration.
